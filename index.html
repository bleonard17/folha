How folha. works

This is an experimental, weather-informed planning tool—not a live foliage monitor. Its colors and peak dates are estimates and should never be treated as verified leaf conditions.

1. Typical timing

Each location begins with an approximate peak date based on regional autumn travel guides and local tree habitat. A broad peak window is shown to avoid false precision.

2. Weather adjustments

When available, Open-Meteo daily weather history adjusts timing up to five days: recent cold nights may advance the estimate; sustained warmer afternoons may delay it. These are simple heuristics, not a scientifically validated foliage model.

3. Visiting conditions

Forecast temperature, rainfall and wind affect the visit recommendation. Weather details only appear when the API provides them for the date you selected. Predictions beyond the forecast horizon use seasonal estimates only.

4. What it cannot know

It cannot measure present leaf pigmentation, forest-specific species composition, drought stress or storm-related leaf loss. The satellite status section currently has no validated observations. It only shows a stage if a separate processing pipeline produces an explicitly validated record. Copernicus imagery can be explored externally.

5. Satellite research

Sentinel-2 catalog search and satellite foliage analysis are separate features. Map background tiles are vector cartography, not satellite images or live foliage measurements.
